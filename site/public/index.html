README로 추천

설치 전에 다 보여 줌

함께 설치되는 스크립트·참고 파일을 같은 규칙으로 검사하고, 플러그인이 실행하는 훅·MCP 서버를 원문으로 보여 준 뒤 검사한 커밋 그대로 설치합니다. 같은 이름 스킬을 덮어쓰면 미리 알립니다.

즐겨찾기

스킬과 GitHub 저장소에 별을 눌러 모으고, 종류·제공자·카테고리로 골라 봅니다.

팀과 나누기

설치한 스킬을 프리셋 파일로 내보내면 팀원이 같은 확인 창을 거쳐 같은 스킬을 설치합니다. 앱이 없는 사람에게는 위험 신호와 설치 명령이 담긴 공유 링크를 보냅니다.

# 실제 화면

점수가 왜 그렇게 나왔는지까지

관련도·인기·최신성·신뢰도를 막대로 보여 주고, 설치 수·별·마지막 수정일·라이선스를 한눈에 봅니다.

실행될 명령을 먼저 보고 설치

개인(모든 프로젝트) 또는 특정 프로젝트 범위를 고르면, 실제로 실행할 명령과 설치 위치, 함께 설치되는 파일의 검사 결과와 훅·MCP 원문을 보여 준 뒤에 설치합니다. 명령은 복사해 직접 실행해도 됩니다.

# 시작하기

  1. 01준비

    Node.js 22.20 이상과 git이 필요합니다.

  2. 02실행

    터미널에서 npx @seojin08/skill-finder

  3. 03사용

    브라우저에 127.0.0.1:4317이 열립니다. 끄려면 터미널에서 Ctrl+C. 계속 쓰려면 npm install -g @seojin08/skill-finder 뒤 skill-finder로 켭니다.

  1. 01내려받기

    skill-finder-win.zip을 받아 원하는 곳에 압축을 풉니다.

  2. 02실행

    SkillFinder.exe를 더블클릭하면 설치되고 바탕화면에 Skill Finder 바로가기가 생깁니다. 다음부터는 바로가기로 켜고, 4317 포트가 이미 쓰이고 있으면 비어 있는 포트를 고르는 창이 뜹니다.

  3. 03사용

    브라우저에 127.0.0.1:4317이 열립니다. 검은 창을 닫으면 꺼집니다.

Chrome이 "일반적으로 다운로드되지 않는 파일"이라고 막으면

바이러스가 발견됐다는 뜻이 아니라, 새로 배포된 서명 없는 프로그램이라 받아 간 사람이 적다는 뜻입니다. 다운로드 목록에서 의심스러운 파일 다운로드(또는 계속)를 누르면 받을 수 있습니다. 실행할 때 Windows가 "알 수 없는 게시자"라고 하면 추가 정보 → 실행을 누르세요.

받은 파일이 이 페이지의 원본과 같은지 확인하려면 PowerShell에서 Get-FileHash skill-finder-win.zip를 실행해 아래 값과 비교하세요.

필요한 것

  • Windows 10 / 11 · macOS · Linux
  • Node.js 22.20 이상 — Claude Code를 네이티브 설치 프로그램으로 깔았다면 따로 설치해야 합니다. 없으면 SkillFinder.exe가 알려 줍니다
  • git — GitHub 저장소 파일 목록을 읽을 때 사용
  • Claude Code — 스킬 설치·삭제에 사용

알아 두기

  • 스킬 1만 3천여 개가 담긴 색인이 함께 들어 있어 처음 켜자마자 검색됩니다. 그 뒤에 바뀐 것만 뒤에서 모읍니다.
  • 설정 화면에 GitHub 토큰을 넣으면 GitHub 검색이 더해지고 별 수도 최신으로 유지됩니다.
  • 검색어는 영어가 가장 정확합니다. 한국어로 적으면 영어 검색어를 제안합니다.
  • 업데이트는 자동입니다. 켤 때마다 새 버전이 있는지 보고, 있으면 내려받아(서명·크기·SHA-256 확인) 바꿉니다. 서명이 맞지 않으면 받지 않습니다. 새 버전이 켜지지 않으면 이전 버전으로 저절로 되돌립니다. 스킬 목록·기록·토큰은 %LOCALAPPDATA%\SkillFinder에 있어 그대로 이어집니다.
  • 0.1.0을 쓰던 경우이 zip을 받아 한 번 실행하세요. 이전 폴더의 data\와 .env를 새 폴더에 넣어 두면 옮겨 줍니다.

# 안전하게 만들었습니다

  • 내 PC의 127.0.0.1에서만 열립니다. 같은 네트워크의 다른 기기도 접속할 수 없습니다.
  • 검색어는 찾기 위해 skills.sh·GitHub로 보냅니다. 검색 기록·색인·토큰은 이 PC의 %LOCALAPPDATA%\SkillFinder에만 저장하고 밖으로 보내지 않습니다(토큰은 GitHub에만 씁니다). skills CLI 사용 통계 전송은 기본으로 끕니다.
  • 스킬의 코드를 실행하지 않습니다. 설치는 실행될 명령을 먼저 보여 준 뒤에만 합니다.
  • AI를 호출하지 않습니다. 검색과 점수는 모두 공개 정보로 계산합니다.
  • 위험 등급은 정해 둔 규칙으로 판정한 것이라 안전을 보증하지 않습니다. 설치 전에 보여 주는 파일과 명령을 확인하세요.
  • 코드는 GitHub에 공개되어 있습니다(MIT). 보안 문제는 저장소의 Security 탭으로 비공개로 알려 주세요.
