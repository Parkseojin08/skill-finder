## 설계 결정

- [#746b] 트리 조회: tree API가 `truncated: true`이면 contents API를 경로별로 부르는 대신 git 부분 fetch로 전체 트리를 다시 받는다. 호출 수가 1회로 고정되고 비인증 상태에서도 동작한다.
- [#580e] git 부분 fetch로 받은 트리에는 파일 크기가 없다. 이 경우 파일 목록의 `size`는 `null`이고, 파일 원문 보기는 raw 다운로드를 256KB에서 끊어 판정한다.
- [#7755] git 작업 폴더는 `data/tmp/git/` 아래에 만들고 목록을 뽑은 뒤 바로 지운다. checkout을 하지 않으므로 원격 파일이 작업 트리에 풀리지 않는다.
- [#4035] 마지막 커밋 시각(F): 저장소 메타(`pushed_at`)가 있으면 그것을, 없으면 색인한 commit의 커밋 시각을 쓴다.
- [#6d35] 커밋 SHA 해석은 `git ls-remote`로 한다(API 한도를 쓰지 않음). 상대경로 플러그인의 `plugins.sha`에는 마켓플레이스 저장소의 현재 commit SHA를 넣어 증분 동기화 키로 쓴다.
- [#5a45] 상대경로 source와 `metadata.pluginRoot`: 베어 이름은 `pluginRoot`에 붙인다. `./`로 시작하는 경로는 `pluginRoot`를 붙인 경로가 트리에 있으면 그쪽, 없으면 마켓플레이스 루트 기준으로 해석한다(문서와 skills CLI 해석이 달라 둘 다 수용).
- [#532d] 일반 저장소 모드는 skills CLI와 같게 name·description이 없는 SKILL.md를 건너뛴다. CLI가 `--skill`로 설치하지 못하기 때문이다. 플러그인 모드는 Claude Code처럼 모든 필드를 선택으로 본다.
- [#6009] `shellInjection` 판정: `` !`cmd` ``는 줄 시작·공백·`(` 뒤에 올 때만 인정한다(`warning!` 같은 문장 끝 느낌표 오탐 방지). ```` ```! ```` 블록은 줄 시작 기준.
- [#17f7] `pluginRootDependency`는 `${CLAUDE_PLUGIN_ROOT}`와 `$CLAUDE_PLUGIN_ROOT`를 모두 잡는다. 판정 대상은 SKILL.md 본문이다.
- [#44b8] 위험 등급: `rmRf`는 "정보성"이므로 단독으로는 medium으로 올리지 않는다.
- [#9aa0] 플러그인 수준 위험 신호(hooks/MCP/bin/monitors)는 그 플러그인에 속한 스킬마다 붙인다. 스킬을 설치하면 플러그인 전체가 설치되기 때문이다.
