# ARASAKA_IN — 숨겨진 미니게임 명세 (v2)

검색창에 `arasaka_in`을 입력하면 열리는 텍스트 RPG. CyberCode Online(이하 "원작")의 **시스템 구조**를 분석해 같은 장르로 새로 만든다.

v1(파일 탐색기에서 버튼을 눌러 자동 전투 결과만 보는 방식)은 "직접 할 수 있는 게 없다"는 평가를 받아 버렸다. v2는 원작처럼 **던전을 직접 걸어 다니고, 전투에서 매 턴 무기·아이템을 고르는** 게임이다.

## 1. 분석 방법과 경계

- 원작 본체는 로그인 뒤에 있어서 계정을 만들거나 로그인하지 않았다. 서버와 통신하지 않았다.
- 원작의 공개 자료만 **읽어서 이해**했다.
  - 공식 소개 페이지
  - 공개 저장소의 튜토리얼 문서(데스크톱·모바일)
  - 튜토리얼 스크린샷: 던전 방, 전투 화면, 퀘스트 대화, 기차역
- 공개 저장소의 라이선스는 "원작 전용, 다른 프로젝트 사용 금지"다. 그래서 그 안의 글·이름·수치·이미지·코드는 **하나도 가져오지 않는다**.
  - 가져온 것은 장르 관습 수준의 **구조**뿐이다. 예: "방을 다 정리해야 문이 열린다", "무기 세 종류가 서로 다른 탄약을 쓴다".
  - 장소·적·아이템 이름, 대사, 수치 공식은 모두 새로 만든다.

## 2. 분석 결과: 원작의 시스템 지도

### 2.1 핵심 루프

허브 도시 → 기차로 구역 이동 → 길거리 적과 싸우거나 던전에 들어간다 → 경험치·돈·장비 상자 → 허브에서 상자 인쇄, 제작, 정비 → 더 높은 구역으로 간다.

- 진행을 막는 관문은 **열쇠**다.
  - 한 구역에는 던전이 셋 있다. 각 던전 보물방에서 그 구역의 **열쇠 조각**이 하나씩 나온다.
  - 조각 셋을 허브 터미널에서 합치면 다음 구역이 열린다.

### 2.2 전투 (턴제)

- 화면 구성
  - 위에 적 이름·레벨, 아래에 적과 나의 체력(+실드) 막대가 있다.
  - 그 밑에 **아이템 칸 3개**(회복제)와 **무기 카드 3장**이 있다. 무기 카드에는 피해량과 남은 탄약이 보인다.
  - 왼쪽 위에 도주 버튼이 있다.
- 무기 셋은 쓰임새가 다르다.
  - 주무기: 탄약이 필요 없고 피해가 가장 낮다.
  - 특수무기: 에너지 탄약을 쓴다. 실드에 강하다.
  - 파괴무기: 반물질 탄약을 쓴다. 피해는 가장 높지만 실드에 약하다.
- 실드가 먼저 깎이고 그다음 체력이 깎인다. 적 공격은 내 방어구 수치만큼 줄어든다.
- 아이템(회복)은 **던전 안에서만** 쓸 수 있다. 길거리 전투에서는 회복할 수 없지만 도주는 항상 성공한다.
  - 던전 안에서 도주는 도주 능력치로 확률을 굴린다. 실패하면 한 대 맞는다.
- 적 수식어(예: 공격 증가, 방어 증가, 큰 실드, 치명타 증가)가 이름 앞에 붙어서 같은 적도 위험도가 달라진다.
- 플레이어 능력치는 치명타·치명 피해·회피·기절·도주·재생·흥정 등 16개이고, 대부분 상한이 있다.
- 사망("플랫라인")하면 아이템은 잃지 않는다. 일정 레벨부터는 돈과 경험치를 조금 잃고 잠시 행동할 수 없다.

### 2.3 던전

- 방이 문으로 이어진 지도다. 방 하나는 `#` 벽이 있는 격자이고, 플레이어는 `@`다.
- 표시
  - 적: 아이콘
  - 상자: 전리품
  - `?`: 퀘스트 주는 NPC. "아이템 몇 개를 주면 일정 시간 버프를 준다"는 거래다.
  - `!`: 세계관 조각글
  - 가장자리: 문. 들어간 문은 회색으로 바뀐다.
- 방의 적을 **모두 처치해야** 문과 상자를 쓸 수 있다. 보물방에는 적이 5마리 이상 있고, 도전 던전이면 보스가 있다. 보물방에 열쇠 조각 상자가 있다.
- 체력은 던전 안에서 자동으로 회복되지 않는다(재생 능력치 제외). 그래서 회복제 관리가 핵심이다.
- 가끔 상자를 열거나 적을 쓰러뜨릴 때 **반응 속도 미니게임**(정해진 순서대로 빠르게 누르기)이 끼어든다. 실패하면 다시 시도한다.
- 던전 종류: 일반, 도전(보스), 갱단 전용. 원작은 여럿이 함께 들어가 적 체력을 나눠 깎는다.

### 2.4 장비

- 슬롯 7개: 주무기, 특수무기, 파괴무기, 머리, 상의, 하의, 신발.
- 등급 6단계(쓰레기 → 일반 → 고급 → 희귀 → 전설 → 에픽). 등급이 높을수록 능력치가 높고 **모듈 슬롯**이 많다.
- 장비 레벨이 내 레벨보다 높으면 장착할 수 없다.
- 장비는 주로 **상자(캐시)**로 얻는다. 허브의 분자 프린터에서 돈을 내고 인쇄한다.
  - 인쇄된 장비 레벨은 **인쇄 숙련도**와 같다.
  - 인쇄와 분해(고철 얻기)를 할수록 숙련도가 오른다.
- 업그레이드 모듈을 장비 슬롯에 끼워 능력치를 더한다. 모듈 레벨은 장비 레벨을 넘을 수 없다.
- 고레벨용 "보정"(확률적으로 부서지는 강화)도 있다. 이번 범위에서는 뺀다.

### 2.5 제작·숙련도·방치

- 재료
  - 의료 부품 → 회복제
  - 탄약 부품 → 에너지 탄약
  - 군용 부품 → 반물질
  - 고철 → 여러 용도
- 숙련도: 인쇄, 의료, 탄약, 채집, 채굴. 숙련도가 높을수록 더 좋은 회복제를 만들고, 같은 재료로 탄약을 더 많이 만든다.
- 상업 지구의 **일감(AFK)**: 시간을 걸어 두면 숙련도·재료·돈이 쌓인다.

### 2.6 허브 시설

| 원작 시설의 역할 | ARASAKA_IN 대응 |
|---|---|
| 상자 → 장비 인쇄 | 나노 포지 |
| 무기 판매·매입·수리 | 도크의 무기고(판매·매입·탄약) |
| 의료품 상점 | 펄스 약국 |
| 열쇠 조각 합성·잠긴 상자 | 브루트포스 터미널(열쇠 합성 + ICE 크래킹 미니게임) |
| 기차역(구역 3개 + 던전) | 마그레일 역 |
| 일감(AFK) | 긱 보드 |
| 플레이어 시장 | 블랙마켓(매일 09:00 레벨 맞춤 재입고) |
| 은행·가방 교환·치장·유료 화폐 | 뺀다 |

### 2.7 퀘스트

- 일반 퀘스트: 처치·인쇄 같은 단일 과제다. 끝나면 바로 다음 과제가 나온다.
- 던전 퀘스트: `?` NPC가 주는 아이템 교환이다. 보상은 버프다.

### 2.8 여럿이 하는 시스템

공동 던전, 플레이어 시장, 서버 전체 버프, 갱단, 전체 채팅. 이 게임에서는 4장처럼 혼자 하는 방식으로 바꾼다.

## 3. ARASAKA_IN v2 설계

### 3.1 화면

전체 화면 게임 UI. 어두운 바탕에 청회색 글자, 노란 강조색을 쓴다. 패널 모서리는 비스듬히 잘라 낸다.

- **상단 바**: 레벨·경험치, 체력·실드 막대, 크레딧, 적용 중인 버프, 위치, 보스키 버튼, 닫기 버튼.
- **왼쪽 메뉴**: 도시 / 장비 / 가방 / 제작 / 퀘스트 / 일감.
- **가운데**: 현재 화면(도시 지도, 시설, 역, 던전, 전투).
- **오른쪽**: 통신 로그(사건·NPC 대화), 진행 중인 일감, 퀘스트 요약.
- **보스키**: `` ` `` 키나 버튼을 누르면 즉시 VS Code처럼 보이는 가짜 편집기로 바뀐다. 원작 데스크톱판의 "일하는 척" 기능에 해당한다. 다시 누르면 돌아온다.
- **Esc**: 게임을 닫는다. 전투·대화·미니게임 중에는 닫히지 않는다.

### 3.2 직접 조작

- **던전**: 15×11 격자 방을 방향키·WASD로 움직이거나, 칸을 눌러 그 칸까지 걸어간다.
  - 적에게 부딪히면 전투, 상자에 닿으면 열기.
  - `?`에 닿으면 거래 대화, `!`에 닿으면 조각글.
  - 열린 문에 닿으면 옆 방으로 간다. 오른쪽에 미니맵이 있다.
- **전투**: 매 턴 고른다.
  - 공격: `1` 주무기, `2` 특수무기, `3` 파괴무기
  - 아이템: `Q`·`W`·`E` 칸
  - `X` 도주
  - 피해 숫자가 튀어 오르고, 적은 0.35초 뒤에 반격한다.
- **미니게임**
  - 신호 동기화: 화살표 순서를 제한 시간 안에 입력한다. 던전 상자의 일부에서 나온다.
  - ICE 크래킹: 4자리 코드 추리. 터미널에서 하고, 3분 쿨다운이다.

### 3.3 구역과 적

구역 5개. 각 구역에 길거리 지역 3개와 던전 3개(일반·도전 중 선택)가 있다. 이름은 모두 새로 지었다.

| # | 구역 | 레벨 |
|---|---|---|
| 1 | 하수 순환로 | 1–9 |
| 2 | 네온 바자르 | 9–18 |
| 3 | 데이터 항만 | 18–28 |
| 4 | 아콜로지 하층 | 28–40 |
| 5 | 블랙월 경계 | 40–55 |

- 적 수식어(새로 정함): 광폭(공격↑), 장갑(받는 피해↓), 방벽(큰 실드), 경련(회피), 저격(치명타↑), 거대(체력·공격↑).
- 던전 크기: 방 6~8개(도전 +2). 일반 방의 적은 1~3마리(도전 2~3)이고, 보물방은 적 3 + 정예(도전이면 보스)다. 원작(방마다 3~4마리)보다 적은 것은 혼자 회복제만으로 통과해야 하기 때문이다.
- 상자의 25%는 신호 동기화로 잠겨 있다. 실패하면 다시 하거나 포기(상자 파괴)한다.
- `?` 의뢰인의 제안은 처음 만날 때 정해진다. 거절했다 다시 와도 같은 제안이라, 다시 굴릴 수 없다.
- 던전 입장: 내 레벨이 던전 레벨 −6 이상이어야 한다.
- 열쇠: 구역 i의 조각 3개 + 크레딧 → 구역 i+1 해금.

### 3.4 장비·능력치

- 슬롯 7개와 등급 6개는 2.4의 구조를 따른다. 수치 공식은 새로 정했다.
  - 무기: 피해
  - 방어구: 체력·실드·방어, 부가 능력치(치명타·치명 피해·회피·도주·기절·재생)
  - 상한: 치명 60%, 회피 35%, 기절 25%, 도주 85%
- 모듈: 등급에 따라 0~3칸. 능력치 하나를 더하고, 언제든 빼서 가방에 넣을 수 있다.
- 상자: 무기·방어구 × 등급. 나노 포지에서 인쇄한다. 레벨 = min(인쇄 숙련도, 내 레벨).
- 장비를 분해하면 고철과 인쇄 경험치를 얻는다.

### 3.5 체력 규칙

- 실드는 전투마다 가득 찬다.
- 체력은 던전 밖에서 시간이 지나면 회복된다. 도시에서는 빠르고 길거리에서는 느리다. 던전 안에서는 회복되지 않는다(재생 능력치 제외).
- 플랫라인
  - 던전 진행이 끝나고, 10초 동안 행동할 수 없다.
  - 레벨 5부터 크레딧 10%와 현재 레벨 경험치 10%를 잃는다.

### 3.6 코드 구조 (`web/src/game/`)

엔진은 브라우저와 게임 서버(Cloudflare Worker)가 **같은 코드**를 쓴다. 그래서 결정적이어야 한다.

- 시간은 `Clock { now, utcOffsetMin }` 인자로만 받는다.
- 무작위는 상태 안의 PRNG(`GameState.rng`, sfc32, uint32 4개)로만 굴린다.
- `Date.now`, `Math.random`, `window`, `localStorage`를 쓰지 않는다.

| 층 | 파일 | 하는 일 |
|---|---|---|
| 내용 | `data.ts` | 구역·적·장비 이름, 회복제, 버프, 대사 |
| 기반 | `rng.ts`, `core.ts` | PRNG, 상태 타입, 능력치 계산, 장비·적 생성, 보상, 시간(09시 초기화, 회복) |
| 시스템 | `combat.ts` → `dungeon.ts`, `town.ts` | 전투 / 던전 생성·이동·상자·의뢰인 / 길거리·장비·인쇄·제작·상점·블랙마켓·터미널·일감·퀘스트·오버클럭·레이드 |
| 진입점 | `actions.ts` | `applyActions(state, actions, clock)`. 묶음 단위로 전부 적용하거나 전부 거부한다. `publicState`는 PRNG를 지운 상태(서버 → 브라우저) |
| 저장 | `backend.ts` | `GameBackend` 인터페이스. 지금은 `LocalBackend`(브라우저 저장소)이고, 온라인에서는 같은 행동을 API로 보낸다 |
| 입력 | `input.ts` | 키 → 게임 입력 대응표. 상황별로 다르다(던전에서 W는 위, 전투에서는 단축칸 2) |
| 화면 | `ArasakaGame.tsx`, `ui/*` | 도시·시설, 던전(Canvas 2D + `requestAnimationFrame`), 전투(턴 사건을 차례로 재생), 대화·미니게임, 장비·가방·제작·퀘스트, 보스키 |

- 의존 방향은 한쪽뿐이다: 내용 → 기반 → 전투 → 던전·도시 → 진입점. 순환 참조가 없다.
- 화면은 엔진 상태를 그리기만 하고, 바꾸는 일은 모두 행동으로 보낸다.

### 3.7 밸런스 확인 (시뮬레이션)

| 확인 | 결과 |
|---|---|
| 같은 시드·같은 행동 | 결과가 항상 같다. 거부된 묶음은 입력 상태를 바꾸지 않는다 |
| 길거리, 같은 레벨 적, 주무기만 | 모든 레벨에서 승리. 한 판에 체력 6~19% 소모 |
| 일반 던전, 그 레벨·흔한 장비·회복제 6개 | 정리율 97~100% |
| 도전 던전 | 정리율 35~63%(어렵게 만든 것이 맞다) |
| 레이드 승률 | 혼자 0~3%, 용병 1명 6~38%, 2명 84~97% |
| 던전 생성 400개 | 닿지 않는 문·물건 0개, 생성에 개당 약 3ms |

- 적의 체력·공격은 그 레벨에 흔한 장비 등급(초반 폐품·일반 → 후반 전설)에 맞춰 커진다. 그래서 후반에도 전투가 시시해지지 않는다.
- 회복제 단계마다 그 단계가 열리는 레벨의 체력 약 40%를 회복한다.

## 4. 여러 명이 필요한 시스템 → 혼자 하는 방식

하루 초기화는 **매일 오전 9시, 플레이어 컴퓨터의 시간대 기준**이다.

| 원작 | ARASAKA_IN |
|---|---|
| 플레이어끼리 거래하는 시장 | **블랙마켓**. 9시가 지나 처음 열 때 그때 레벨로 재입고한다. 장비 4개, 상자 2개, 회복제 묶음, 탄약 묶음을 각각 한 번씩만 판다 |
| 공동 던전·실시간 협동 보스 | **레이드**(하루 한 번). 용병 0~2명을 고용하고 일반 전투 화면에서 직접 싸운다. 용병은 내 턴 뒤에 자동으로 공격하고 쓰러질 수 있다. 보스는 무작위로 한 명을 노린다 |
| 기부형 서버 전체 버프 | **오버클럭**. 크레딧을 내면 30분간 피해 +20%, 일감 보상 +50% |
| 갱단·순위 | 도시의 **순위표**. NPC 크루와 점수를 비교한다 |
| 전체 채팅 | 오른쪽 통신 로그에 NPC 대화가 주기적으로 올라온다 |
