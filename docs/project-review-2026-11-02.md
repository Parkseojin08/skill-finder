## 틀리거나 과장된 지적
1. r1의 "content-type 2.1.0 / 루트 1.0.5"는 틀렸다. 실제로 도는 버전은 같고, 진짜 차이는 qs·encodeurl 2개다.
2. r3의 "git에 README가 하나도 없다"는 일부 틀렸다(`server/scripts/bench/README.md`는 추적됨). 루트 README가 없다는 뜻이면 맞다.
3. r2의 "CLI 덮어쓰기 질문을 `-y`가 건너뛴다"는 과장이다. 덮어쓰기 전용 질문은 없고, 요약의 `overwrites:` 뒤 일반 확인 하나다. 앱 확인 창에 덮어쓰기 정보가 없다는 핵심은 그대로다.
4. r3의 P0 등급(배포 코드 git 밖, 릴리스 검사 없음)은 다소 높다. 지금 깨진 동작은 없다. 비용이 S이고 실패하면 전원에게 퍼지므로 1차에 넣는다.
5. r1의 `/API` 우회는 범위를 정확히: 다른 사이트는 응답을 못 읽고 JSON 본문이 필요한 설치·삭제·설정은 못 바꾼다. 그래도 약속이 깨졌고 수정이 S라 P0.
6. 서버가 `emitCandidates` 예외로 죽는 경로(r1-10)와 IsUp 오판의 빈도는 추측이다.
